⛑ 현장 위험성평가 도우미

평가표를 한 번 작성하면 안전관리시스템 작업등록이 자동으로 채워지고, TBM 입간판사진에 평가표가 자동 첨부됩니다.

1. 버튼 코드 복사

2. 크롬 즐겨찾기로 저장 (갤럭시)

  1. 크롬으로 아무 페이지(이 페이지도 OK)에서 오른쪽 위 ⋮ → ☆를 눌러 즐겨찾기에 추가
  2. 아래쪽에 뜨는 수정을 누르기 (놓쳤으면 ⋮ → 북마크에서 방금 추가한 항목 길게 눌러 수정)
  3. 이름: 위험성평가 로 바꾸기
  4. URL 칸 내용을 모두 지우고 복사한 코드 붙여넣기 → 저장

3. 사용하기

  1. 크롬에서 safe.skons.net 로그인
  2. 주소창을 누르고 위험성평가 입력 → 아래 목록에 뜨는 ☆ 위험성평가 즐겨찾기를 누름
    (주소창에 글자만 치고 엔터를 누르면 검색이 돼요. 꼭 목록의 별 표시 항목을 누르세요.)
  3. 📝 평가표 작성 → 작업등록 자동입력 → 평가표 작성 후 맨 아래 📤 안전관리시스템에 자동입력
  4. 채워진 내용 확인 후 [등록하기]는 직접 누르기
  5. TBM 3단계로 가면 입간판사진에 평가표가 자동 첨부됨. 안 붙었으면 즐겨찾기를 한 번 더 눌러 📎 첨부 선택

알아두기

  • 회사 앱 안에서는 동작하지 않아요. 크롬 브라우저로 접속해서 쓰세요.
  • 등록하기·저장 버튼은 도우미가 누르지 않아요. 최종 확인과 등록은 본인이 합니다.
  • 작업명·사유 칸에 이름, 연락처 등 개인정보는 적지 마세요.
